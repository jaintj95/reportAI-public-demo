Help

Ask a question in plain English. Relay selects a reviewed report for common questions or builds a custom query for other reporting needs. Every query is checked before it reads the e-Builder data warehouse. Tables show the fetched values, and answers identify missing data and the measures used.

Open the step above an answer to see the exact SQL.

The warehouse is refreshed once a night. When the question, recent context and data match a saved answer, Relay reuses it at no AI cost.

Follow-up questions can refer to recent messages in this chat. Relay asks for clarification when a reference is unclear. Refreshing this tab restores the chat. New chat or Sign out clears the saved copy; closing the tab ends its storage.

Name the project and describe the document information you need. Relay looks up the project in e-Builder, searches live file names and folders, and downloads and reads relevant files. You do not need a filename or file ID. It can read up to three files per answer and shows checked quotations and source locations. If the project is unclear, it asks you to identify it. The shared API account determines access. Document lookup/download times appear with the answer; the header date applies to the warehouse.

Open a source card and choose Preview source to see the cited text highlighted in nearby extracted context. Download original opens an authenticated link on Relay’s domain; PDF originals can open at the cited page. Links last 15 minutes in the same sign-in session. Ask again for a new link. Preview layout may differ from the original.
